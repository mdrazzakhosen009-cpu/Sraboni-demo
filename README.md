# Sraboni Style Corner
Premium purple + white clothing e-commerce site.

Render:
- Build Command: npm install
- Start Command: npm start
- Recommended env: ADMIN_PASSWORD and DATABASE_URL

Admin: /admin.html
Default password if ADMIN_PASSWORD is not set: admin12345

Note: this demo uses memory for orders/reviews; add PostgreSQL persistence before production if long-term data retention is required.
